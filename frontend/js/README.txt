Pliki JavaScript strony:

- script.js      -> główna logika strony (home, sklep, portfolio, modal, formularze, muzyka)
- admin.js       -> główny panel administratora
- admin-blog.js  -> moduł zakładki "Blog" w panelu administratora
- blog.js        -> logika strony bloga (wpisy + komentarze + logowanie użytkowników)
